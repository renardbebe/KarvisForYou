## 天气架构重构：心知天气 → Open-Meteo
彻底移除心知天气 API 依赖，改用 Open-Meteo（完全免费、无需 API Key、开源、数据准确）。

### 新架构
- **Open-Meteo Geocoding API**: 城市名 → 经纬度（支持中文，先中文搜再英文 fallback）
- **Open-Meteo Forecast API**: 经纬度 → 当前天气 + 当日预报
- **内置 50+ 城市坐标缓存**: 国内主要城市 + 国际常用城市，减少 Geocoding 请求
- **WMO Weather Code → 中文天气描述映射**
- **统一 `fetch_weather()` 函数**: 供 skill handler 和 app.py morning_report 共用

### 修改文件
1. `src/skills/weather_query.py` — 完全重写，Open-Meteo API + Geocoding + 城市缓存
2. `src/app.py` — `_build_weather_context()` 改为调用 `weather_query.fetch_weather()`，删除 80 行重复代码
3. `src/config.py` — 移除 `WEATHER_API_KEY` / `SENIVERSE_KEY`，只保留 `WEATHER_CITY`
4. `setup.sh` / `docs/部署指南.md` / `docs/requirements.md` — 清理心知天气相关说明

### 验证结果

## 天气查询 504 超时 Bug 修复
今早 08:00 晨报天气获取失败，日志显示 `Open-Meteo 返回 504`。

### 根因
Open-Meteo API 偶尔返回 5xx，而 `fetch_weather()` 只请求一次就放弃，无重试机制。

### 修复
`src/skills/weather_query.py` 的 `fetch_weather()` 增加重试机制：
- 默认 3 次重试（`_retries` 参数可调）
- 5xx 和网络异常（Timeout/ConnectionError）触发重试
- 间隔递增：2s → 4s
- timeout 从 8s 提升到 10s
- 4xx 等客户端错误不重试，直接返回 None

## 联网搜索 (web.search) Skill 新增
用户反馈 Karvis 听不懂"我在听立春"是歌曲、"屋檐沥水滴滴答"是歌词。根因：DeepSeek V3.2 训练数据有截止日期，且不可能覆盖所有歌词/小众作品。

### 技术方案
利用项目已有的**阿里云百炼 Qwen API** 原生支持的 `enable_search` 联网搜索参数（零成本接入），实现两阶段搜索：
1. DeepSeek 主调用 → 判断需要搜索 → 输出 `skill="web.search"`
2. 调 Qwen（qwen-plus + enable_search=true）联网搜索 → 搜索结果注入上下文 → DeepSeek 再次生成自然回复

### 修改内容
1. **新建 `src/skills/web_search.py`**:
   - `search()` handler：接受 `{query, context?}` 参数
   - `_call_qwen_search()`：调用阿里云百炼 Qwen API（enable_search=true）
   - 使用 qwen-plus 模型以获得更好的搜索理解
2. **`src/prompts.py`**:
   - `SKILL_PROMPT_LINES` 添加 `web.search` 描述
   - `RULES_CORE` 新增"联网搜索"规则段：
     - 明确 LLM 知识有截止日期
     - 定义必须搜索的场景（不确定的作品名、歌词/台词、实时信息）
     - 给出判断标准（<90% 把握 → 搜索）
     - query 生成指南和反面案例
3. **`src/brain.py`**:
   - `process()` 中 Agent Loop 之后新增"V-Search 搜索结果二次加工"逻辑
   - 新增 `_generate_reply_with_search()` 函数：把搜索结果注入对话历史让主模型生成最终回复
   - `_NO_REROUTE_SKILLS` 和 `_SKIP_NOTE_SKILLS` 注册 `web.search`

### 验证
容器内实测搜索"立春 歌曲 歌词 屋檐沥水滴滴答" → 成功识别：薛凯琪原唱（2024年），准确给出歌词，还纠正了"沥水"应为"雨落"
