# 2026-03-24 工作日志

## settings.frequency — 支持通过对话调整主动推送频率

### 问题
用户发送"每天主动询问的次数降低为1次"，Karvis 将其误判为情感表达（"自我调节情绪"），输出诗意心灵解读，而非执行配置修改。

### 根因分析（两层）
1. **LLM 路由错误** — RULES_CORE 中无频率调整路由，LLM 找不到对应 skill，把消息当闲聊自由发挥
2. **系统能力缺失** — `COMPANION_MAX_DAILY=3` 和 `SCHEDULER_PUSH_MAX_DAILY=6` 硬编码在 config.py，无 per-user 覆盖机制

### 修改内容（4 文件，+109/-6）

1. **`src/skills/settings.py`** — 新增 `set_frequency()` + 注册 `settings.frequency`
   - 支持 companion_max(0-5)、push_max(1-10)、action(query/set) 参数
   - per-user 存储到 user_config.json 的 frequency 字段
   - 返回 memory_updates 记录用户偏好

2. **`src/prompts.py`** — 路由规则
   - SKILL_PROMPT_LINES 添加 settings.frequency 描述
   - RULES_CORE 新增「推送频率调整」完整路由规则（触发信号 + 参数推理 + 边界约束）
   - 明确标注为操作指令而非情感表达

3. **`src/app.py`** — per-user 频率覆盖
   - `_run_companion_check` 读取 frequency.companion_max 覆盖全局 COMPANION_MAX_DAILY
   - companion_max=0 时直接跳过主动关怀
   - `_scheduler_tick` 读取 frequency.push_max 覆盖全局 SCHEDULER_PUSH_MAX_DAILY

4. **`src/brain.py`** — 防护注册
   - settings.frequency 加入 _NO_REROUTE_SKILLS 和 _SKIP_NOTE_SKILLS
